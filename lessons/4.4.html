4.4 · Files & Analysis: Documents, Images, Data

PDFs, images, spreadsheets, screenshots — and the analysis tool that writes real code to compute real answers. Claude's senses, and when to trust each one.

In one breath: Claude reads documents and images natively and can run actual code on your data files via the analysis tool — the operator's rule: eyes for reading and judgment, code for counting and math.

What Claude can take in

Documents: PDFs (including scanned ones — it reads page images), Word files, text, markdown, code files. Long docs ride the 1.2/3.2 physics you already master. Images: photos, screenshots, charts, diagrams, whiteboards, handwriting. Real vision — it reads the chart's axes, the error dialog's text, the handwriting's content (4.1's camera-as-scanner, formally blessed). Data files: CSVs and spreadsheets — where the professor/calculator split becomes critical. Limits exist (file size, page counts, images per chat) and shift with plans and releases — when you hit one, the workaround is usually 3.1 thinking: split, summarise per part, synthesise.

The analysis tool: Claude's calculator

When enabled, Claude can write and execute code (JavaScript in the app's sandbox) against your uploaded files — actually computing sums, averages, joins, filters, charts — and then explain the results. The difference is not cosmetic: Question Eyes (reading) Code (analysis) «What does this contract say about termination?» ✔ perfect fit overkill «What's the average order value in this CSV?» ❌ plausible guess ✔ computed fact «Summarise the tone of these reviews» ✔ judgment task can count, can't feel «Which month had the most refunds, and by how much?» ❌ hallucination bait ✔ groupby + arithmetic The operator's law: numbers about your data come from code, not from reading. The magic phrase when it matters: «use the analysis tool / compute this with code, and show the code.» Seeing the code is your 1.6 verification path — you (or a fresh chat) can check the logic.

Files out, not just in

Claude also CREATES files — formatted documents, spreadsheets, presentations — downloadable from the chat. The workflow shape that unlocks: messy input file → analysis → clean deliverable file, all in one conversation. (At Cowork altitude this becomes folder-scale — Track 5; the chat version is your training wheels and often all you need.) The screenshot super-habit: any time something on screen confuses you — an error, a chart, a form, a setting — screenshot it into Claude with «what am I looking at and what should I do?». It's the highest-frequency vision use in real life, and it works far more often than people expect.

Recap

Eyes for reading and judgment, code for counting and math — demand the analysis tool with visible code for any number about your data, spot-check one figure per deliverable, and screenshot anything confusing.
