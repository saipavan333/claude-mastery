7.4 · Slash Commands, Modes & Checkpoints

The cockpit: slash commands for control, permission modes from cautious to autonomous, and checkpoints — the undo system that makes boldness cheap.

In one breath: Slash commands operate the session (/help, /context, /compact, /rewind and custom ones you write); permission modes set the autonomy dial (ask-first → plan-only → auto-accept); checkpoints snapshot before every change so any step can be rewound.

Slash commands: the session's control panel

Type / and the panel opens. The daily set (as of July 2026): /help — the map when lost. /context — what's on the desk right now (1.2, instrumented!): see what's consuming your window. /compact — summarise-and-continue when the session grows long: the 2.7 restart ritual as a built-in (it compresses history, keeping decisions). /rewind — the recovery door (checkpoints, below). /usage — where your plan's allowance stands (1.5's meter, live). /review — ask for a code review of recent changes. /plan — enter plan mode. Custom commands — your macros: drop a markdown file in .claude/commands/ and it becomes a slash command: your «/receipts» that runs your standard verification, your «/ship» that tests-then-commits. Templates (3.5) with a cockpit button. Teams share them via the repo — house macros, versioned (7.3's philosophy extending).

Permission modes: the autonomy dial, formalised

You've run the default (ask-before-acting). The full dial (names vary slightly by surface; the LADDER is the point): Mode Behaviour Your 5.2 instinct says Plan mode Read-and-propose ONLY — no edits, no commands. Pure architect. Unfamiliar codebases, big designs, «what would you do?» explorations — zero risk by construction Standard (ask-first) Every edit and command proposed for approval Default; new task types; anything touching things you can't easily restore Auto-accept edits File edits proceed; commands still ask Proven task types in git-protected folders — the productive cruise setting Full auto / bypass Runs without asking Sandboxes and containers only — isolated environments where nothing real can break (how Claude Code on the web runs, safely, in Anthropic's cloud sandbox) The law is 5.2's, word for word: autonomy scales with reversibility — and this track ENGINEERED reversibility (git, checkpoints), which is why higher modes are legitimately usable here. Mode-per-task, not mode-as-personality.

Checkpoints: boldness, underwritten

Automatic snapshots: Claude Code checkpoints state before changes — a running series of restore points independent of your git commits. /rewind (or double-Escape): step back to any checkpoint — code, conversation, or both. The wrong turn that used to mean archaeology now means one command. The two-layer net: checkpoints = fine-grained undo within a session; git commits = deliberate save-points you CHOSE (7.2's rhythm). Fly with both: checkpoints make experiments free; commits make progress durable. What the net changes about YOU: «try the risky refactor», «attempt the big cleanup» stop being scary asks — worst case is a rewind. Teams with strong undo systems demonstrably attempt more ambitious changes; you're now such a team of one-plus-agent.

Recap

Navigate with slash commands (and write your own), set the autonomy dial per task on the reversibility law, and fly boldly on the two-layer net — checkpoints for free experiments, commits for durable progress.
