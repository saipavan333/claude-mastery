4.1 · The Tour Most Users Never Take

Web, desktop, mobile — same Claude, different superpowers. The fifteen-minute tour that most users never take, and the settings that quietly matter.

In one breath: The Claude app runs on web, desktop and mobile with the same brain but different powers per platform — and ten minutes in Settings (styles, keyboard habits, chat organisation) permanently upgrades every future session.

Three platforms, three personalities

Platform Where it shines Unique powers Web (claude.ai) The full-featured home Everything renders best here: Artifacts, Projects, Research, file previews. Zero install; works on any machine. Desktop app (Mac/Windows) Deep work & local reach The gateway to Cowork's local-file powers (Track 5), local MCP servers (Track 8), global shortcut to summon Claude, and it keeps sessions a keystroke away all day. Mobile (iOS/Android) Capture & continue Camera as an input device (snap a document, a whiteboard, a broken appliance), voice conversations, and continuing the same chats you started at your desk. The operator pattern is continuity : start research on your phone in a queue, refine it on the web at your desk, hand the files to Cowork via desktop. One account, one history, three entry points.

The settings ten minutes that pay forever

Styles: the app can apply response styles (concise, explanatory, formal — or custom ones you create from a writing sample). A custom style is a standing system prompt (2.6) wearing a friendly UI — set one up for your default voice. Model picker: now that you speak fluent 1.3, actually use it per task instead of living on the default. Feature toggles: check what's enabled — web search, analysis tool, artifacts. A surprising number of «Claude can't do X» complaints are a toggle someone never opened. Keyboard habits (web/desktop): new chat in one stroke, Shift+Enter for newlines (write multi-paragraph prompts — your 2.1 skeletons deserve line breaks), Edit on your last message to fork a better version instead of appending «no wait, I meant…» (cleaner context — 1.2). Chat hygiene: rename important chats, delete dead ones, use search to resurrect old work. Your history is a knowledge base if you keep it findable — and its best contents should graduate into Projects (next lesson).

Inputs people forget exist

Paste is powerful: screenshots paste directly into the box (an error dialog, a chart, a WhatsApp thread) — Claude reads images natively (more in 4.4). Voice on mobile: dictation for prompts-while-walking, and full voice conversations where available — thinking out loud with a colleague who never tires. Camera as scanner: a photo of a menu, contract page, or handwritten notes is a legitimate document input. The habit: if your eyes can read it, Claude probably can too. Edit-and-fork: editing an earlier message re-runs the conversation from that point — your iteration tool (2.7) for fixing the prompt instead of arguing downstream.

Recap

Web is the full home, desktop is local reach, mobile is capture — set a Style, fork instead of arguing, rename what matters, and let chats travel with you.
