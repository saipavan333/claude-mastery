7.7 · Beyond Code: Files, Research, Ops

Beyond code: the terminal agent as a general-purpose power tool — data, documents, media, research, and ops — the non-coder's full inheritance, claimed.

In one breath: Claude Code's powers — read anything, transform anything, run any tool, script any repetition — apply to EVERY structured domain: data wrangling, document pipelines, media processing, system housekeeping, research compilation; «code» was always just the first customer.

The five territories (with the tools it wields for you)

Data: merging, cleaning, deduplicating, reshaping, reconciling — spreadsheets, CSVs, exports, logs. The agent writes and runs real data code (pandas and friends) with your 3.3/5.3 contracts as law. Anything the analysis tool (4.4) did in chat, at 10× the scale and repeatability. Documents: batch conversions (formats, encodings), splitting/merging PDFs, extracting text from scans (OCR tools — it installs what it needs, with your approval), template-filling at scale, building indexes across archives. Media: images resized/renamed/watermarked/compressed in batches (ImageMagick and kin); audio/video converted, trimmed, transcribed (ffmpeg, Whisper-class tools) — the entire «I need to do X to 300 files» genre, solved as a category. Research & compilation: fetch-and-extract across sources, structured note-building, bibliography wrangling, cross-referencing archives — 4.6's research discipline with file-system hands. Ops & housekeeping: backups with verification, folder audits (duplicates, space hogs, stale files), migration between tools/formats, config surgery — the digital chores of a life or business, scripted once, kept forever.

Why the terminal wins these jobs

Repeatability: chat produces an answer; the terminal produces a SCRIPT — an asset that runs monthly forever (Rekha's arc). One-off help vs owned automation: the whole 3.5 asset philosophy, at full power. Scale: 4.5's artifacts and 4.4's analysis have sandbox limits; the terminal has your actual machine — 30,000 files is Tuesday. The world's toolbox: decades of open-source tools (the ImageMagicks and ffmpegs) are suddenly YOURS — the agent knows them, installs them (approval flow!), and drives them. You're not limited to what Claude can do; you're limited to what ANY tool can do, which is roughly everything. The discipline transfers untouched: contracts, receipts, quarantines, copies-first, hooks on the sacred — every law from Tracks 3–7 applies verbatim, because they were never about code either.

The claiming ritual (how a non-coder takes territory)

Start each territory with an audit commission: «look at this folder and tell me what a professional would notice» — the agent maps the terrain before you commit to outcomes (plan-mode thinking, 7.4, applied to domains). Commission the script, keep the script: always ask for the reusable version + a plain-English «how to run this again» note in the folder. Assets, not favours. Let it teach the territory (7.1's education, per domain): «explain what ffmpeg just did» — ten sessions in, you speak enough of each tool's language to spec better commissions. Competence compounds sideways. Graduate recurring territory up the staircase: the monthly ones become skills + schedules (you know this by heart now — 6.4's bell rings everywhere).

Recap

The terminal never cared what the files were: claim data, documents, media, research and ops with audit-first commissions, keep every script as an owned asset with a run-note, and let each territory teach you its language.
