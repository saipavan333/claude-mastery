1.4 · The Map: Every Place Claude Lives

One brain, seven bodies. The map of every place Claude lives — and the fastest way to know which one your task wants.

In one breath: The same Claude models power the chat app, Cowork, Claude Code, the Chrome extension, Excel, Slack/Microsoft 365, and the developer API — surfaces differ in what they can touch (files, browser, terminal, your code), not in intelligence.

The seven surfaces

Surface What it is Its superpower Claude app (web · desktop · mobile) The conversation home: chat, Projects, files, Artifacts, Research, connectors, Skills. Thinking together: writing, analysis, learning, planning. Cowork Agentic workspace inside the app — give Claude folders and an outcome; it works through multi-step tasks, even after you close the laptop. Delegation: finished documents, organised files, synthesized research. Claude Code (terminal · desktop · web) An agent in your development environment: reads files, edits, runs commands, tests, commits. Building software — and, quietly, any file-heavy technical work. Claude for Chrome Browser extension: Claude sees pages, clicks, types, fills forms. Web-bound work: research across sites, form-filling, web-app chores. Claude for Excel Add-in inside spreadsheets: reads workbooks, explains formulas, edits with cell-level citations. Spreadsheet jobs where the spreadsheet must stay a spreadsheet. Claude in Slack / Microsoft 365 Claude joins your team's chat and documents. Shared team assistant where collaboration already happens. Claude API + Agent SDK The raw programmable brain, for software you build. Products and automation serving other people — where businesses get built.

One skill, compounding everywhere

The map explains why this course is ordered the way it is. Everything you learn in Phase B — prompting — transfers to all seven surfaces , because they share the same brains. Learn to write one great instruction and you've upgraded your chat sessions, your Cowork delegations, your Claude Code commands, and the system prompts of products you'll ship. Skills compound; surfaces multiply them. The deeper pattern across surfaces is reach : what can Claude touch? Chat sees your words and files you hand it. Cowork reaches folders and connected apps. Code reaches your repository and terminal. Chrome reaches the live web. The API reaches whatever you wire it to. More reach = more leverage = more responsibility — which is why permission systems appear on every agentic surface, and why we treat them seriously from Lesson 5.2 onward.

The 10-second surface picker

Thinking, writing, learning, one-off analysis → the app . «Here are my files, come back with finished work» → Cowork . Anything in a repository, terminal, or codebase → Claude Code . The task lives across websites you'd click through → Chrome . The deliverable IS a workbook → Excel . Teammates need to see and join in → Slack / M365 . It must run 1,000×, on a schedule, or inside your product → API . Wrong-surface pain is real: pasting code file-by-file into chat (Claude Code exists), copying data cell-by-cell (Excel exists), doing the same report manually every Monday (Cowork's scheduled tasks exist). If a task feels clunky, you're probably on the wrong square of the map.

Recap

One brain, seven bodies: chat for thinking, Cowork for delegation, Code for repos, Chrome for the web, Excel for workbooks, Slack for teams, API for scale — and clunkiness means wrong surface.
