16.1 · One App: Cowork, Chat, Docs & Slides

The 2026 consolidation: chat and Cowork became one app, and Claude gained Docs, Slides, and in-conversation Design. What moved where, and how to work the new surface.

In one breath: As of September 2026, Claude's chat and Cowork merged into a single app, with Claude Docs and Slides (beta) and Design available right inside a conversation — so thinking, automating, and producing polished deliverables now happen in one place instead of three, and the old 'which surface do I open?' question mostly answers itself.

What merged, and why it matters

The change is structural, not cosmetic. Previously chat (fast, conversational) and Cowork (agentic work on folders, from Track 5) were separate apps with separate mental models. Now they're the same app: you can start a casual question and, in the same thread, hand Claude a folder and a task and let it work — the coworker (5.1) is always one sentence away, not a different door. Two consequences for you as an operator: No more surface-switching tax. The 6.4 «surface picker» still matters for Chrome vs Excel vs Code, but the chat-vs-Cowork fork — the one you hit twenty times a day — is gone. Escalate from talk to work in place. Memory follows you. Cloud memory now spans chat and Cowork (the 4.3 memory, unified), so context you built while chatting is there when Claude starts doing — less re-briefing, the theme of this whole course.

Docs, Slides & Design — makers in the flow

The bigger unlock is on the output side. Claude can now produce polished artifacts in the conversation : Claude Docs — a living document you and Claude edit together: it drafts, you comment, it revises, and the document keeps its own version history. Think 4.5's Artifacts grown into a real editor for reports, briefs, and specs. Claude Slides — the same idea for decks: describe the talk, hand it the facts, get a structured presentation you refine slide by slide (the pptx skill of 4.8, now a first-class surface). Design — visual generation right in the thread for a diagram, a social graphic, a simple layout — no separate tool. The discipline from earlier tracks transfers exactly: a Doc or a deck is still load-bearing text , so you still verify its claims (1.6) and ground it in real facts (3.4). The maker got faster; the judgment stayed yours.

The operator's new map

Re-internalize the surfaces as they stand in September 2026: one app for chat + Cowork + Docs/Slides/Design (think, automate, produce — in one thread); Claude Code for agentic building in a repo (Track 7); Claude in Chrome for work that lives in the browser (16.3); Claude for Excel for spreadsheet-native work (6.2); the API / Agent SDK for products you build for others (Tracks 9–10). The rule is still 6.4's: match the surface to where the work already lives. What changed is that the most common daily choice got simpler, and the last mile — turning good thinking into a shippable document — moved inside the conversation.

Recap

In September 2026 Claude's chat and Cowork merged into one app, and Claude Docs, Slides, and in-conversation Design moved production into the thread. The daily chat-vs-Cowork fork is gone: you escalate from talking to doing in place, memory follows you across the surface, and you finish deliverables without switching tools. The surface got faster; the verification discipline (1.6/3.4) stayed exactly where it was — with you.
