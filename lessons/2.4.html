2.4 · Controlling the Output: Formats & XML Tags

Format is free money: the same intelligence, delivered in the exact shape you can use. XML tags are the power move nobody taught you.

In one breath: Tell Claude precisely what shape the answer should take — structure, length, sections, tables, JSON — and use XML tags to fence off parts of your prompt and demand labelled parts in the response.

Specify the shape like an architect

Claude will happily produce any structure — but only one of you knows which structure you need. Say it: Skeleton specs: «Structure: (1) one-line verdict, (2) three numbered findings each with a supporting quote, (3) a 2-column table of risks vs mitigations, (4) recommended next step in bold.» Length per part beats length overall: «verdict under 20 words; each finding 2–3 sentences» is far more controllable than «keep it short». Markdown on request: tables, headers, bold, checklists — claude.ai renders them beautifully, and they paste into docs cleanly. Machine formats: ask for JSON or CSV when a spreadsheet or script is the destination — and give a tiny example of the exact schema (Lesson 2.3's move). In Track 9, this graduates into structured outputs , where the API can guarantee schema-perfect JSON. Negative space: say what to omit — «no preamble, no closing summary, start directly with finding 1» kills the throat-clearing.

XML tags: fences for the prompt, labels for the response

Here's the professional's favourite tool. XML-style tags — like <document>…</document> — are just labelled brackets, and Anthropic explicitly recommends them because Claude is trained to respect them. Two uses: Use 1 — fence your inputs. When a prompt mixes instructions with pasted material, ambiguity is dangerous — is that sentence in the pasted email an instruction to follow or content to analyse? Fences end the confusion: <email>…the customer's email…</email> <policy>…your refund policy…</policy> «Using the policy in <policy>, draft a reply to the email in <email>.» Now Claude knows exactly what is material and what is command — this precise confusion, weaponised, is called prompt injection, and fencing is your first taste of the defense (full story: Lesson 8.5). Use 2 — demand labelled output. «Respond with your reasoning in <thinking> tags, then the final reply in <answer> tags.» Now a human can read just the answer — or a script can extract it with one line of code. Labelled outputs are the hinge between chatting and automation.

Templates: format specs you reuse

The compounding move: when you find a format that works, save the spec. A «weekly report format», a «meeting minutes format», a «client proposal format» — each is 5 lines of format instructions you paste (or, from Lesson 3.5, template properly; from 4.8, install as a Skill). Professionals don't re-describe shapes; they own a shelf of moulds.

Recap

Design the output shape before you prompt, specify parts and lengths, fence inputs and label outputs with XML tags, and ban the preamble — format control turns drafts into deliverables.
