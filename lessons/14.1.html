14.1 · Capstone A: Personal Automation Suite

Capstone A — build a Personal Automation Suite: three-to-five real automations plus a reusable Skill and a scheduled task that run your work life, packaged as your first portfolio piece.

In one breath: This first capstone consolidates the Power-User phase (Tracks 4-6) into a working Personal Automation Suite — a small set of automations (inbox triage, a weekly report, a file organizer, a research digest), one reusable Skill, and one scheduled task — that together demonstrate you can turn Claude into infrastructure that does real work on a schedule, not just answer questions.

The build brief (what you're making)

A Personal Automation Suite is a small collection of Claude-powered automations that handle your recurring work. Your brief: Pick 3-5 recurring tasks you do regularly that Claude can handle: triaging an inbox or message queue, turning notes into a weekly report, organizing/renaming/sorting files, producing a research or news digest, drafting recurring communications, cleaning and summarizing incoming data. Choose YOUR real tasks — the suite should save YOU time. Build each as a repeatable automation using the right surface (Track 6's surface picker): Cowork (Track 5) for anything touching your files and folders; a Project (4.2) with saved instructions for recurring document work; a connector (4.7) for tasks inside your tools. Each automation should be a documented, repeatable process — not a one-off. Package one as a reusable Skill (4.8): take your best, most-repeated automation and turn it into a Skill so Claude performs it consistently every time, your way. This demonstrates the packaging skill that separates operators from casual users. Schedule at least one (5.5): make one automation run on a schedule (a Monday-morning report, a daily digest) so it works without you — the clearest demonstration of Claude as infrastructure. The deliverable is the working suite PLUS a one-page write-up (what each automation does, the time it saves, how it's built) — that write-up is the portfolio artifact.

The architecture (how the pieces fit)

Think of the suite in three layers, each mapping to skills you built: Inputs: where work arrives — a folder of files, an inbox, a data export, a topic to research. Cowork (5.2/5.3) reads folders; connectors (4.7) reach your tools; the app handles pasted or uploaded material. Processing: the Claude instructions that transform inputs into outputs — your prompts (Tracks 2-3), packaged as Project instructions (4.2) or a Skill (4.8) so they run consistently. This is where your prompting craft becomes reusable infrastructure. Outputs + cadence: where results go (a report file, an organized folder, a digest document — Cowork writes them, 5.4) and WHEN they run (on demand, or scheduled — 5.5). The cadence layer is what makes it a SUITE (a system that runs) rather than a set of prompts you re-type. The whole point: you're building repeatable PROCESSES, not asking one-off questions. Each automation = a defined input, a packaged instruction, a defined output, and a cadence. That's the operator's mental model, made concrete.

Acceptance criteria (how you know it's done well)

A portfolio-grade suite meets these bars: It actually runs repeatably. Each automation works the same way each time — you can run it (or it runs on schedule) and get consistent, correct output. A one-time result isn't an automation. It saves measurable time. You can state the time each automation saves ("the weekly report went from 90 minutes to 5"). Portfolio pieces need numbers (11.5) — measure them. The Skill is genuinely reusable. Your packaged Skill (4.8) produces consistent results across different inputs — it's a real, portable capability, not a single prompt. The scheduled task fires and delivers. Your scheduled automation (5.5) runs on its cadence and produces the output without you starting it — verified over at least one cycle. It's documented. The one-page write-up explains each automation clearly enough that someone else could understand what you built and why — this is what makes it a PORTFOLIO piece (7.8/13.3), not just a personal convenience.

Recap

Capstone A is a Personal Automation Suite: 3-5 repeatable automations (inbox triage, reports, file organization, digests, drafting) built on the right surfaces (Cowork, Projects, connectors), with ONE packaged as a reusable Skill and ONE running on a schedule — each verified, measured for time saved, and documented in a one-page portfolio piece; it proves you can turn Claude into infrastructure that does real, repeatable work, and it frees the time everything else you build stands on.
