6.4 · The Surface Picker: Right Tool, Right Job

The surface picker: one decision framework that routes any task to the right Claude — and the graduation exam for the whole power-user phase.

In one breath: Route by four questions — where does the work live, is it conversation or delegation, is it one-off or recurring, what's the blast radius — and compose surfaces freely: the operator's answer is usually a pipeline, not a place.

The four routing questions

1. Where does the work LIVE? The container decides the surface: repository → Claude Code · workbook → Excel add-in · live web pages → Chrome · your folders → Cowork · team channels → Slack/M365 · your head/one document → the app. (1.4's map, now with reflexes.) 2. Conversation or delegation? Am I thinking WITH Claude (iterative, judgment-heavy → chat/app) or handing over an OUTCOME (specifiable, receipt-checkable → Cowork/scheduled)? The 5.1 shift, as a fork. 3. One-off or recurring? One-off → do it on the spot. Recurring → template it (3.5) → skill it (4.8) → schedule it (5.5). The staircase IS the routing for anything that repeats. 4. What's the blast radius? Reversible → autonomy welcome. Irreversible (sends, deletes, payments, publishes) → human hinge, whatever the surface. The one law that overrides all convenience (5.2, 6.1, 6.3 — thrice-learned, once-stated).

Composition: the operator's real answer

Real tasks route through PIPELINES of surfaces — and you've already seen every pattern: Research → app → Cowork: investigate (4.6) → decide the structure in chat → delegate the document-set build (5.4). Chrome → Excel → Slack: extract the web dashboard (6.1) → model it in the workbook (6.2) → post the summary with citations (6.3). Cowork → schedule → team: prove the report delegation (5.4) → put it on the clock (5.5) → human-dispatch to the channel (6.3). Everything → skills: your procedures (4.8) fire on every surface — the connective tissue that makes seven tools feel like one system. The composition habit: name the pipeline before starting («this is Chrome-extract → sheet-model → channel-post») — one sentence that prevents the mid-task surface-shuffle where files and context get lost between tools.

The Phase C exit checklist

Honest self-audit — you should now be able to: Run the app like an operator: rooms with law (4.2), memory dials set (4.3), files computed-not-eyeballed (4.4), artifacts shipped (4.5), research briefed-and-audited (4.6), connectors scoped (4.7), procedures installed (4.8). Manage delegation: outcome specs with quarantines and receipts (5.1–5.3), office artifacts you sign (5.4), automation with honest failure (5.5), an operation with law and rooms (5.6). Work embedded: browser with hinges (6.1), grids with citations (6.2), teams with norms (6.3). Route and compose all of it on reflex (this lesson). Anything unchecked: that lesson's lab is your homework before Track 7. The builder phase assumes ALL of it — Claude Code will feel like Cowork with the guardrails moved, BECAUSE it is.

Recap

Container, mode, cadence, consequence — route every task in one breath, compose pipelines by name, climb the staircase on repetition, and let the hinge law override everything. Phase C: complete.
